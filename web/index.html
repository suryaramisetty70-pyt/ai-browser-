    Connect your browser

    Ask AI works immediately with a connected provider. Browser tasks use the Chrome or Edge companion to control a separate task tab.

    1. Download and extract the companion ZIP.
    2. Open chrome://extensions or edge://extensions and enable Developer mode.
    3. Choose Load unpacked, select the extracted folder containing manifest.json, then reload DeskPA.
